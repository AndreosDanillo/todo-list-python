📝 Gerenciador de Tarefas (To-Do List) em Python

Programa de terminal para gerenciar tarefas do dia a dia, desenvolvido em Python como projeto de estudo.

📌 Sobre o projeto

Este projeto permite adicionar, listar, concluir e remover tarefas por meio de um menu interativo no terminal. Foi criado para praticar lógica de programação e estruturas de dados básicas do Python.

✅ Funcionalidades

- Adicionar tarefa: cadastra uma nova tarefa com título
- Listar tarefas: mostra todas as tarefas numeradas, com status [ ] (pendente) ou [X] (concluída)
- Marcar como concluída: altera o status de uma tarefa escolhida
- Remover tarefa: exclui uma tarefa da lista
- Sair: encerra o programa

🛠️ Conceitos utilizados

- Listas e dicionários
- Laço while (menu em loop) e for com enumerate()
- Estruturas condicionais (if, elif, else)
- Operador ternário
- f-strings
- Módulo "os" (limpeza do terminal)

▶️ Como executar

1. Tenha o Python 3 instalado
2. Clone este repositório:
```bash
   https://github.com/AndreosDanillo/todo-list-python.git
```
3. Entre na pasta do projeto:
```bash
   cd todo-list-python]
```
4. Execute o programa:
```bash
   python todo_list.py
```
